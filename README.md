## 三、加作品（有新成片时）

打开 `index.html`，往下找 `WORKS` 数组，复制一份条目并改内容，例如：

```js
{
  title: "张先生 & 李小姐 婚礼",
  date: "2026.10",
  type: "video",                        // 直接播视频文件
  src: "https://wedding-video-1441297017.cos.ap-shanghai.myqcloud.com/xxxx.mp4?q-sign-algorithm=...",  // ← COS 私有播放链接
  poster: "https://你的封面图地址.jpg",  // 封面图（可留空，自动显示首帧）
  concept: "这支影片的创作理念：……"
}
```

**视频怎么传（你只需把成片文件给我，其余我来做）：**
1. 视频传到腾讯云 COS 私有空间（当前在 `wedding-video`，上海地域，仅你有权限访问）
2. 我生成一条**一年有效的私有播放链接**填进 `src`
3. 页面内直接播放，客人不用再输任何码；链接到期后找我重新生成即可

## 四、视频隐私说明（腾讯云 COS 私有方案）

| 层级 | 作用 |
|---|---|
| 页面密码 | 拦住不知道密码的访客，防搜索引擎收录 |
| COS 私有空间 + 签名链接 | 视频文件本身不公开：只有页面里那条带签名的链接能打开，链接一年有效 |

说明：视频藏在腾讯云私有存储里，公开仓库里只有网页代码，不含视频文件。客人需要「网址 + 页面密码」才能看到页面，再通过页面里的签名链接播放视频。签名链接如果被完整复制转发，拿到的人也能看（相当于转发视频文件本身），这是云端播放方案的正常边界。
