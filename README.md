# 夏天天的婚礼影像 · 作品集

一个专为婚礼摄像师设计的电子作品集小站：**输密码才能进**，进站后客人可以直接在页面里看你的作品视频和每支影片的创作理念。风格为「冰橙美式」复古文艺风（暖米底 + 焦糖橙 + 浅棕线条，参照你发的 PPT 模板参考图）。

## 二、改访问密码

1. 用记事本 / VS Code 打开 `index.html`
2. 搜索 `PASSWORD`，找到这一行：

   ```js
   var PASSWORD = "5201314"; // ← 你的访问密码，记得改成自己的
   ```

3. 把 `"5201314"` 换成你自己的密码，保存即可

> 说明：页面密码存在网页代码里（前端校验），作用是**拦住不知道密码的访客、防止搜索引擎收录**，属于"便捷锁"。要让视频本身严格保密，靠的是下面的方案 B：视频放 YouTube「不公开」，只有拿到链接的人才能看，页面再套一层密码，双保险。

## 三、加作品（有新成片时）

打开 `index.html`，往下找 `WORKS` 数组，复制一份条目并改内容，例如：

```js
{
  title: "张先生 & 李小姐 婚礼",
  date: "2026.10",
  type: "embed",        // 你选的方案 B：嵌入播放
  src: "https://www.youtube.com/embed/xxxxx",  // ← 视频嵌入地址
  poster: "https://你的封面图地址.jpg",        // 封面图（可选）
  concept: "这支影片的创作理念：……"
}
```

**方案 B 怎么拿嵌入地址（一次性的，很简单）：**
1. 把成片传到 YouTube，可见范围选 **不公开（Unlisted）**——只有拿到链接的人能看，别人搜不到
2. 打开视频页 → 点「分享」→ 点「嵌入」→ 复制代码里 `src="..."` 的那段网址（形如 `https://www.youtube.com/embed/xxxx`）
3. 把这段网址填到作品的 `src` 里即可，客人点开就是页面内直接播放，不用再输任何码

> `type` 还有两种备选：`"video"`（直接播视频文件 mp4）、`"link"`（跳转网盘链接+提取码，隐私最强）。不会改代码？直接把新作品的视频和理念发我，我帮你加。

## 四、视频隐私说明（已定方案 B）

| 层级 | 作用 |
|---|---|
| 页面密码 | 拦住不知道密码的访客，防搜索引擎收录 |
| YouTube「不公开」 | 视频本身不出现在公开列表，只有拿到链接的人能打开 |

页面和视频是双重保护：客人需要「网址 + 页面密码」才能看到，而视频文件本身不公开、不参与搜索。这是目前免费、体验最好的组合。

## 五、部署到 GitHub Pages

### 首次部署（约 5 分钟）

1. **注册 / 登录 GitHub**：去 https://github.com 注册（免费）。
2. **新建仓库**：点右上角 `+` → `New repository`，仓库名如 `wedding-portfolio`，**选 Public**（免费版 GitHub Pages 需要公开仓库），点创建。
3. **上传文件**：进入新仓库 → `Add file` → `Upload files` → 把本文件夹里的 `index.html`（和 `README.md`）拖进去 → `Commit changes`。
4. **开启 Pages**：仓库页面 → `Settings` → 左侧 `Pages` → `Source` 选 `Deploy from a branch`，`Branch` 选 `main`，目录 `/ (root)` → `Save`。
5. 等 1–2 分钟，页面顶部会出现 `Your site is live at https://你的用户名.github.io/wedding-portfolio/` —— 把网址 + 密码发给客人即可。

### 以后更新作品

- 改 `index.html` 后：仓库页面 → `Add file` → `Upload files` 重新上传覆盖 → `Commit`，等 1 分钟页面自动更新。
- 也可以用 Git 命令行推送（`git add .` → `git commit` → `git push`），需要时我帮你操作。
